
# Portfolio Project

This is a portfolio project built with React, TypeScript, Vite, and CSS Modules. It showcases my skills, projects, and experiences as a developer.

## Features

- Clean and modern design
- Responsive layout for different screen sizes
- Smooth navigation using React Router
- Dynamic content rendering
- Interactive components and animations
- TypeScript for type safety and improved development experience
- CSS Modules for scoped and reusable styles
- Optimized build and fast development server with Vite

## Prerequisites

Make sure you have the following installed:

- Node.js (v14 or higher)
- npm (v6 or higher)

## Getting Started

1. Clone the repository:

git clone https://github.com/your-username/portfolio-project.git


2. Navigate to the project directory:

cd portfolio-project


3. Install the dependencies:

npm install


4. Start the development server:

npm run dev


5. Open your browser and visit `http://localhost:3000` to see the portfolio in action.

## Building for Production

To create a production build of the portfolio, run:

npm run build


The optimized and minified files will be generated in the `dist` directory.

## Running Tests

To run the tests, use the following command:

npm test


This will run the test suites using Jest and React Testing Library.

## Deployment

The project was deployed using Vercel.

## Project Structure

- `src/`: Contains the source code files
  - `components/`: Reusable components used throughout the portfolio
  - `pages/`: Top-level pages or sections of the portfolio
  - `styles/`: Global styles and CSS Modules
  - `utils/`: Utility functions and helpers
  - `App.tsx`: Main application component
  - `index.tsx`: Entry point of the application
- `public/`: Public assets and files
- `tests/`: Test files
- `vite.config.ts`: Vite configuration file
- `tsconfig.json`: TypeScript configuration file
- `.eslintrc`: ESLint configuration file
- `README.md`: Project documentation
